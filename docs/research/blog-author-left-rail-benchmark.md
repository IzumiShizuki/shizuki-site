# 博客与“关于网站”左栏内容调研

调研日期：2026-09-29。范围限定为公开的博客与站点介绍；下文的日历均指**公开文章的发布日期与归档**，不接入 TimePrism 日程、提醒或其他私人数据。

## 建议交付顺序

### 1. 博客左栏：文章日历 + 紧凑作者入口

保留现有四个导航按钮。在它们下方加入一个**单月文章日历**：标题显示年月，前后月切换；今天与“有公开文章的日期”采用不同视觉标记；无文章日期不伪装成链接；点有文章的日期后按该日筛选中间列表，显示清楚的筛选状态和清除入口。同一天多篇时显示列表，不随意跳到其中一篇。月度汇总可以复用现有右栏归档数据，但逐日标记须使用覆盖该月**全部公开文章**的统计，不可仅从当前分页推断。

可在导航与日历之间放一张**很短的作者入口**：复用公开资料的头像、姓名、已有简介字段，链接到“关于网站”；内容缺失时隐藏字段，不填虚构文案。不要再复制最新文章、分类、标签、天气、音乐或引言。

实现时优先复用公开帖子查询的日期范围语义；若逐日统计无法由现有接口可靠取得，可增加按月返回公开发文日期及篇数的轻量聚合接口。按站点约定统一日期时区与周起始日，处理月末、闰年和同日多篇。左栏在 148–176px 宽度时七列格子很紧，应在窄桌面折叠日历或提供清晰的“按日期浏览”入口；移动端放进现有辅助抽屉，避免把整个月格插到文章列表之前。数据加载失败时保留原导航并显示简短重试/空状态。

### 2. 关于网站左栏：小型身份卡 + 同页导航 + 相关路径

公开介绍页当前特意隐藏资料卡。建议只恢复**紧凑版**作者身份：头像、姓名、已有角色/一句简介，并避免把现有三格统计卡完整搬回。下面继续显示现有“关于网站 / 建站经历 / 站点文章”同页导航；再放 2–3 个经过确认的公开入口，例如博客、音乐库、轻应用。若中间已有对应入口，左栏文案应像“从这里开始”而非重复一整张门户卡。社交/联系链接只在公开资料有真实地址时显示。

建站经历若有可公开的日期与标题，可再考虑一个“最近里程碑”单行预览，点击回到对应章节。没有稳定数据时不增加空卡片或编造“网站运行天数”。

### 3. 验收重点

- 日历只使用**已公开文章**的发布日期；不能显示 TimePrism 私人事项、未发布草稿或管理数据。
- 日期、月份、清除筛选能在同一博客列表中往返；同日多篇均可到达。
- 键盘可操作月份按钮与发文日期，当前日/选中日可被文字或可访问名称区分，不能只靠颜色。
- 148px 左栏、980px 以下布局、辅助抽屉以及关于网站的固定侧栏均无横向溢出或双重滚动。
- 页面现有右栏模块与管理员“写文”入口照常工作；无公开资料、无文章或接口报错时不出现空白占位。

## 取舍结论

本轮最值得做的是**公开文章日历**和**轻量作者入口**。它们分别补“何时写过”和“谁在写”的信息，与现有右栏形成互补。完整年度归档、更多统计、社交卡与推荐列表可以等真实内容量和公开数据支撑后再考虑。
