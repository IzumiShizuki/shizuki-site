## Why

项目已有根目录 `AGENTS.md`，但它主要记录协作边界和提交流程；后续智能体仍需要自行摸索模块职责、启动方式、配置位置、测试入口和部署边界。新增一个项目内的 `.agent/` 知识目录，让智能体可以从单一入口快速建立上下文，降低误操作和重复勘探成本。

## What Changes

- 新增 `.agent/README.md` 作为智能体上下文入口和阅读顺序说明。
- 新增项目概览、架构与目录职责、开发命令、配置与环境边界、测试与交付检查等主题文档。
- 记录文档维护规则，要求命令、路径、远端边界和验证结果以仓库现状为准。
- 不修改应用运行时行为、API、数据库结构或部署目标。

## Capabilities

### New Capabilities

本次为纯文档与协作工具建设，没有新增运行时能力，因此跳过 spec delta。

### Modified Capabilities

无。

## Impact

- 受影响范围：仓库新增 `.agent/` 文档目录和 OpenSpec 变更记录。
- 不新增依赖，不改变 Maven、前端或部署配置。
- 文档会引用现有本地工具链路径、远端中间件边界和脚本入口，但不写入凭据。
