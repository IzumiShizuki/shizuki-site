## Why

上线后，从“喜欢的音乐”取消喜欢会出现“没有找到播放列表”错误。声音页当前只有推荐播客，用户还需要选择网易云账号点赞过的声音、收藏的合集及自己的播客合集。

## What Changes

- 复现并修复云端喜欢歌单中取消喜欢后的请求和列表刷新，平台确认后移除曲目，失败保留原状态。
- 在网易云声音页提供“喜欢／收藏的声音”“订阅播客”“我创建的合集”，继续提供推荐和搜索。
- 保留节目 ID 与 mainSong 播放 ID 的区别，按网易云声音收藏语义读取和更新红心状态；公开点赞数与声音收藏是独立接口。
- 隔离账号数据，显示登录/绑定、空态与重试，不用公开推荐冒充个人收藏。
- 复用当前生产基线和已有部署授权，在个人服务器发布此次修正并验收。

## Capabilities

### New Capabilities

- `netease-personal-podcasts`: 网易云账号点赞声音、收藏及自己创建的播客合集与节目喜欢状态。
- `cloud-liked-playlist-refresh`: 云端喜欢歌单取消喜欢后的正确请求、确认与列表刷新。

### Modified Capabilities

无；前次平台音乐库变更尚未归档为主规范，此次以单独能力补充其行为。

## Impact

影响网易云客户端、平台音乐服务/API、普通音乐声音页、喜欢状态与相关测试。沿用加密账号 Cookie、NCM sidecar 和共享播放器，无新依赖或数据库迁移。保留用户 `TopMenu.vue` 修改；不执行 Git push。
