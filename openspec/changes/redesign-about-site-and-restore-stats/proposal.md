## Why

The About page displays zeroes from absent profile statistics and mount-only DOM number animation. Its repetitive rectangular sections also fail to convey the personal site's expressive identity.

## What Changes

- Connect the data overview to existing public post totals, categories and tags, with explicit pending, failure, retry and genuine zero states.
- Render counts reactively so delayed responses and subsequent updates are visible without imperative number animation.
- Redesign the About introduction with asymmetric composition, arched imagery, orbital lines, geometric accents and stronger typography; reshape story sections into a coordinated composition.
- Preserve profile content, editing, links, shared navigation, day/night themes, mobile usability and reduced motion.
- Obtain a Claude design review and verify the result in the browser.

## Capabilities

### New Capabilities

- `about-site-presentation`: Truthful public statistics and expressive responsive presentation of the About page.

### Modified Capabilities

None.

## Impact

Vue About components and component tests; reuse existing public blog endpoints without backend changes or new dependencies. Existing unrelated working-tree changes are excluded from this delivery.
