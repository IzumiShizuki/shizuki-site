## Context

动机见 proposal.md。首页搜索和推荐使用 40px 的 `.te-cover-wrap` 包住行内 `.track-cover`，内部 span 没有独立盒子。歌单与队列的 40px 封面直接作为 flex 子项，默认允许压缩。电台列表的 48px 图片也允许压缩。

## Goals / Non-Goals

**Goals:** 在各自列表内维持已有的正方形封面尺寸，长标题由文字区域截断。

**Non-Goals:** 不调整歌单大封面、播放器大图、主题、导航或播放逻辑。

## Decisions

- 首页封面包装层成为明确的块级盒子，内部缩略图使用 `display: block` 填满包装层；避免只写宽高但没有实际布局盒子。
- 歌单、队列和电台封面禁止 flex 压缩，文字容器允许缩小并显示省略号；不根据图片天然比例或标题长度计算宽度。
- 保留现有 40px / 48px 的列表密度和背景居中裁切。所有变更限制在对应组件样式。

## Risks / Trade-offs

- [固定封面会减少窄列中的文字空间] → 保留文字区域的 `min-width: 0`，验证长标题和窄视口下的省略显示。
- [DOM 单元测试无法证明 flex 实际尺寸] → 使用真实浏览器测量不同标题和封面状态的边界尺寸，并执行现有相关测试及生产构建。
