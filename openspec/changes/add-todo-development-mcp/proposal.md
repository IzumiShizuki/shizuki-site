## Why
A Todo should let a new coding session resume the right stage without replaying a previous conversation.

## What Changes
- Add opt-in development workflows to LightApp Todos, without rewriting legacy Todos.
- Provide scoped MCP search, context, progress and stage submission.
- Show status, next step, history and human approval in TimePrism.

## Capabilities
### New Capabilities
- `todo-development-workflow`: stage-aware developer handoff and progress tracking.

## Impact
Additive migration, content module API, TimePrism UI and local MCP adapter. No publication, deployment or Agent scheduler.
