## Why

普通音乐页的播客资源仍是占位内容，默认歌单和本站红心与已绑定的网易云账号相互割裂。用户需要在普通模式访问平台资源、直接浏览账号歌单，并把点赞同步回所属平台账号。

## What Changes

- 接入网易云声音/播客推荐、节目列表和私人 FM，复用已有账号凭据与共享播放器。
- 从普通音乐页及迷你音乐库移除默认歌单，整合实时平台歌单与用户已有歌单，避免重复展示导入副本。
- 以网易云账号的喜欢列表作为红心状态；点赞和取消点赞调用平台接口，失败时保留原状态。
- 统一普通/Folia 红心状态，按平台和曲目身份隔离，并防止切换网站账号后异步结果污染新账号。
- 尚未部署账号 API 的平台明确报告能力缺失，避免将本站收藏伪装成平台点赞。

## Capabilities

### New Capabilities
- `music-platform-library`: 普通音乐页的平台声音资源、账号歌单与真实点赞同步。

### Modified Capabilities

无。

## Impact

影响 Vue 音乐主页、音乐库上下文、迷你音乐库、媒体模块与网易云 NCM 客户端；新增账号喜欢和声音资源 API。沿用现有网易云 sidecar 和加密账号配置，不新增依赖、不删除已有用户数据。本次在本地完成验证与提交。
