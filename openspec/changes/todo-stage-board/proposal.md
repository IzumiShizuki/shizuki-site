## Why
Task owners need to see which development stage is active and return to the same task from their own notes.

## What Changes
- Display the four existing stages in Todo detail with timing, roles and deliverables.
- Link a device-local Obsidian note and provide a protected return link.
- Add a local CLI stage worker using existing Todo MCP authorization and Codex.

## Impact
Todo detail, the existing development context response, and local Todo tools.
