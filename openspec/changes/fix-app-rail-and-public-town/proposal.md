## Why

轻应用右侧栏随页面高度拉伸后，把空白分配给标题、应用条目与文件夹，导致扫描和操作困难。AI 小镇公开漫游也存在纵向布局松散的问题，且本地前端仍请求未运行的 7070 网关，导致公开场景显示服务不可达。

## What Changes

- 将轻应用栏改为顶部紧凑排列，统一条目高度，并给名称和移除操作分配独立空间。
- 收紧文件夹区的标题、折叠行和展开内容，保留拖放、打开、移除及重命名行为。
- 修正 AI 小镇的顶部与主区域网格轨道，让标题、地图和场景说明按内容排列。
- 验证公开小镇 API 的真实可用入口，修复本地开发的网关连接，并改进场景加载失败后的反馈与重试。

## Capabilities

### New Capabilities

- `compact-lightapp-rail`: 保持当前主题的紧凑右侧栏、可读名称、独立操作区与响应式文件夹布局。
- `public-town-availability`: 公开小镇的紧凑布局、可达 API 请求、加载失败反馈及恢复。

### Modified Capabilities

无。

## Impact

- 前端 `LightAppRailEditor.vue`、`AppsPage.vue`、`AiHubPage.vue` 与相关开发网关配置。
- 相关前端行为测试和浏览器验证；若诊断发现后端问题，在相应服务入口实施最小修复。
- 保持既有主题、公开浏览权限和管理员特殊 NPC/资源管理权限。
