## 已有管理界面

使用 ADMIN 账号打开 `/#/admin`。已有用户、分组、权限、音乐来源、壁纸审核、站点组件等管理界面；相关写操作已有管理员权限码二次验证。

有意向某个账号开放时：

1. 在「分组」创建一个专用自定义分组，例如 `PRIVATE_MEDIA`，或为单个账号建立独立分组。
2. 在「权限」为该分组勾选「音声内容访问」(`music.asmr.access`) 或「外部壁纸访问」(`media.wallpaper.discovery`)。
3. 在「用户」只把明确许可的账号加入该分组。不要为了方便把权限开放给 USER/FRIEND 等大范围内置分组。
4. 音声还有「音乐来源」里的 enabled/visible 开关；来源开关和账号权限都满足才显示前端标签。账号权限覆盖整个音声区，包括所有年龄筛选。
5. 权限调整/部署迁移后让相关账号退出再登录，并等待网关已有授权缓存刷新。

二次元桌宠目前保留 ADMIN-only：登录 ADMIN 后，三秒内连续点击右下角小猫五次（键盘聚焦按钮后按 Enter/Space 同样有效），即进入二次元模式并打开现有 meguri-pet。陪伴窗口和 AI Hub 都有「返回普通模式」。刷新页面、退出登录或切换账号会回到普通模式；`mode=meguri` 链接不能自行开启隐藏模式。

普通桌宠提供专注和音乐快捷操作。网站沿用 meguri-pet 的 Web 适配与认证网关；本次不改动独立桌宠仓库。

## 上线前必须审核的现有公开内容

代码检查不能判断被人为标为 PUBLIC 的图片、音频、头像、歌单描述或封面是否包含色情内容，也不能让曾经公开的 CDN 链接自动失效。此项是生产数据工作，需要在单独授权的部署/内容审查阶段进行。

- 在后台壁纸审核、媒体管理中检查所有 PUBLIC/APPROVED 内容；敏感内容设为 PRIVATE，禁止作为公开主页壁纸/角色。
- 检查登录页图片、站点头像、公开歌单资料与封面、相册和文章中的外链。登录外观配置目前是面向所有访客的站点级配置。
- 核查历史 `music-cache/asmr/` 公共对象与 CDN 缓存，必要时迁到私有存储并移除旧公共对象/链接。新的代码会阻止继续上传，但不会删除历史对象。
- 普通访客的主页仍可能使用已有的公开二次元壁纸/头像；本次隔离的是私有音声、外部未审核壁纸和桌宠角色模式。如果普通入口也要完全中性，应把公开默认素材改成自然风景或纯色。
- 没有账号授权的人仍能访问人工审核的公开壁纸；外部发现区的所有分级都受授权限制，这是对未审核外部内容的保守边界。
