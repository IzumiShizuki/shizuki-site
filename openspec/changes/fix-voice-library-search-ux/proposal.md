## Why

Voice catalogue search silently discards tag selections, can render results from an older query, hides selected tags when result facets change, and eagerly downloads covers.

## What Changes

- Keep keyword and selected tags together, show and restore search context, and make tag choices and result states clearer.
- Cancel or disregard superseded lookups; make additional loading recoverable and defer offscreen covers.
- Preserve the existing catalogue permission and age-rating policy.
